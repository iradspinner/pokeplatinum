# The early kits on the type ladders: a player's read

Written 2026-10-06 on the branch `balance-tm-pass` for Ian's spot-check of the per-type ladders ("climb, don't jump"), which he found good enough for now (`balance-plan.md`). Its tables compared the ladders' first-split attacks with the lists of that day, which have changed since, so they no longer describe the game. The rule lives in the standing rulings (a gap is filled from the type ladder's rung that fits the point in the game; pivots are high rungs) and in `tools/oxide/balance/learnrewrite.py`, whose `start_power` (each split's old ceiling less 20) is the lever if early kits feel off in the alpha. The full read is in git at `cb8a751d01:docs/oxide/early-kits-read.md`.
