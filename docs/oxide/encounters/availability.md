# Availability plan

Generated by `python3 -m tools.oxide.encounters.cli availability --write` from `availability-plan.json`, the sidecar and the tree; do not edit. Authoring plan Step 2: where every evolution line on the species pick-list is meant to be caught, decided before any slot is written. A *home* is the one land table designed for the line; a *cameo* is any other regular appearance; a *tail* is a 4% or 1% one-off (the only wild place for a gate-tier starter); *non-wild* is a gift, trade, static battle, starter or fossil script the tree already has; *water* is a surf or rod table planned as the line's home. *Captures* are per location name and gym split, Ian's nuzlocke rule: two tables under one name are one capture, and a rod table counts from the split its rod arrives in.
