# The Kaizo study's comb reports

Copies of the Kaizo team study's split reports, one per split, from its
folder (`~/oxide-trials/kaizo-teams/out/comb/`), so Ian can read them in the
doc viewer. The study's folder is the source; the Overseer refreshes these
copies each time a split is shown to Ian. The trainer files themselves stay in
the study's folder until step 12 of `docs/oxide/alpha-readiness.md` puts them
in the game.
