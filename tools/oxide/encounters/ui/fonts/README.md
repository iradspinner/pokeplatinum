# Vendored: Pixelify Sans

`PixelifySans-600-latin.woff2` is `files/pixelify-sans-latin-600-normal.woff2`
from **@fontsource/pixelify-sans 5.3.0**, taken with
`npm pack @fontsource/pixelify-sans@5.3.0` on 2026-09-22. It is weight 600, the
latin subset, 8,216 bytes. The licence is the SIL Open Font License 1.1, kept
beside it as `OFL.txt` (Copyright 2021 The Pixelify Sans Project Authors).

It is the tool's pixel display face, and the visual design limits it to
identity: the title, the view and time-of-day tabs, the uplift headline and the
dex number. Anything read or compared stays in the sans or the tabular mono.
The latin subset covers digits, `%`, `×` and A to Z, which is everything those
roles print. `theme.css` declares it with `font-display: block`, because the
file is local and tiny and a swap would make the title jump.
